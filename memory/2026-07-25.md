# KRIPTONSHARE — Notas 2026-07-25

## Tarea solicitada

Implementar Fase 1: Vista Previa Segura de Documentos Microsoft Office, según `KRIPTONSHARE_Fase1_Vista_Previa_Office_Especificacion.md`.

Permitir subir `.docx`, `.xlsx`, `.pptx` y formatos relacionados, convertirlos a PDF en un servicio efímero propio durante el upload, cifrar el preview con la misma contraseña del archivo y que el receptor lo visualice dentro de la app con `pdfrx`.

## Resultados del diagnóstico

### Login
- ✅ El login funciona correctamente tanto para `emisor@kriptonshare.test` como para `receptor@kriptonshare.test`.

### Vista previa Office
- El archivo Word subido quedó registrado en Supabase con:
  - `conversion_status: failed`
  - `viewer_object_key: null`
  - `viewer_file_size_bytes: null`
- El receptor recibió el archivo y el visor descargó el objeto original (`storage_object_key`), no el preview, porque no existe preview. Por eso muestra "Formato protegido".
- Se observó un `RenderFlex overflowed by 7.8 pixels` en `lib/screens/viewer/viewer_screen.dart:311` que hay que corregir.

### Causa raíz probable
- La conversión falló en el paso de upload del emisor. Esto suele ocurrir porque:
  1. El gateway `infra/conversion/` no está desplegado o no es accesible desde la app.
  2. El gateway rechazó el archivo (extensión, límite de tamaño, JWT inválido).
  3. Hubo un error de red o timeout hacia el gateway.

## Resultado de logs del emisor

- Se observó claramente la línea:
  ```text
  I/flutter (10744): [CONVERSION] Falló (network): Error de conversión (HTTP -). Continúa sin preview.
  ```
- Esto confirma que la app no puede conectarse a `AppConstants.conversionServiceUrl` (`https://convert.kriptonshare.com`). El gateway `infra/conversion/` no está desplegado o no es accesible desde el dispositivo.

## Otro problema detectado

- Error en `check_upload_limits`:
  ```text
  PostgrestException(message: Could not choose the best candidate function between: public.check_upload_limits(p_user_id => uuid, p_file_size => integer), public.check_upload_limits(p_user_id => uuid, p_file_size => integer, p_is_folder_upload => boolean), code: PGRST203, ...)
  ```
- Hay overloads duplicados o conflictivos de `check_upload_limits` en Supabase. El flujo tiene fallback cliente, pero debe corregirse en la base de datos.
