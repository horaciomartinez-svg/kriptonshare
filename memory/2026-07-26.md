## Tarea solicitada

Corregir el problema de overload de `check_upload_limits` en Supabase. El error era:

```text
PostgrestException(message: Could not choose the best candidate function between:
public.check_upload_limits(p_user_id => uuid, p_file_size => integer),
public.check_upload_limits(p_user_id => uuid, p_file_size => integer, p_is_folder_upload => boolean),
code: PGRST203, ...)
```

### Firma correcta confirmada
- `lib/providers/file_provider.dart:139` llama la RPC con solo dos parámetros:
  ```dart
  params: {'p_user_id': userId, 'p_file_size': fileSizeBytes}
  ```
- Por tanto, la firma correcta es `public.check_upload_limits(UUID, INTEGER)`.
